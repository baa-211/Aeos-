# DEC-003 — Source of the CLI Version String

## Question
Where does `aeos --version` read its value from?

## Why it is open
The binary cannot currently report what it is. The manifest is authoritative for the project version, but a binary can be run against any project, so reading the target's manifest would report the wrong thing.

## Options
1. **Build-time ldflags.** `-X main.version=...` set from the tag during release. Standard Go practice. Cost: a `go build` without the flag reports an empty or `dev` version.
2. **Embedded constant synchronized by AEOS-VER-001.** The constant joins the set of versions the validator keeps aligned. Cost: another place the version lives, though it would be enforced rather than trusted.
3. **`debug.ReadBuildInfo` from the module version.** No flags needed. Cost: reports `(devel)` for local builds, which is honest but unhelpful during development.
