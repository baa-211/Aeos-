# AEOS CLI

## Mission
Build a small, deterministic, trustworthy repository validator that automatically checks applicable AEOS engineering standards.

## Primary Outcome
A project can run `aeos check` and receive reliable objective findings.

## Non-Goals
No cloud backend, database, dashboard, embedded AI, plugin system, or architecture inference in the MVP.

## Current Milestone
M6 — Dogfood. M1 through M5 are complete; M5 closed on 2026-08-26 with live GitHub Actions evidence.
